# Continuity

Use this room for compact notes that preserve Jeff's working state across
Codex compaction, restart, or context loss.

Notes imported with `jeff memcastle continuity import [path]` belong here.
They should contain durable current-state facts, open work, changed files,
known blockers, specialist handoffs, and verification status. Do not store
secret values here.

When context is visibly tight, roughly around 15% remaining context, create or
update a concise continuity note and import it before compaction can discard the
active working set.
