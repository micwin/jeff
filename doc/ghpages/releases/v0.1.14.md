## Highlights

- Codex integration now lives under a dedicated `jeff codex` command group so the core CLI stays usable even when Codex is unavailable.
- Added a `jeff codex tui` shortcut for launching the full Codex interface without remembering the legacy `chat` name.

- [Debian package](https://github.com/micwin/jeff/releases/download/v0.1.14/jeff_0.1.14_amd64.deb)

## Changes

- move `init`, `ask`, and the new `tui` launcher under a `jeff codex …` namespace to isolate Codex-specific flows
- keep docs/completions/tests in sync with the new command layout so quick-start instructions remain accurate
