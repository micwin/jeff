## Highlights

- **New standalone Jeff menu** – `jeff menu` is now a first-class command with an interactive Bubble Tea UI, inline create/edit/move/delete, Ctrl-T popup integration, and the ability to run outside tmux.
- **Tmux quality-of-life upgrades** – Added `jeff tmux restart`, smarter `kill` handling, session-scoped Ctrl-T bindings, and a dedicated status-line renderer so the overlay always shows your configured path/clock/host segments.
- **Status bar + shortcuts polish** – Label input is optional (falls back to the command), menu entries can be inserted at explicit positions, and the popup works even when no shortcuts are configured.

## Changes

- Promote the shortcut manager to `jeff menu …` with Bubble Tea UI (`a` append, `i` insert, `m` move, `e` edit, `d` delete, Ctrl-T popup refresh).
- Allow menu TUI + `jeff menu show` to run outside tmux (fullscreen) while still integrating with the overlay.
- Add `jeff tmux restart`, improve `jeff tmux kill`, and ensure Ctrl-T bindings only apply to the Jeff session.
- Fix status-line rendering so custom shell commands expand correctly and occupy the full tmux status segment.
- Make menu labels optional and automatically fall back to the command text.
